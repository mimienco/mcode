# Install MCode Mobile on Android

Download and install MCode Mobile on Android.

## Install MCode Mobile

1. Open the MCode download page in Chrome or another full browser and select **Android**.
2. When the download finishes, open your browser's **Downloads** or your device's **Files → Downloads**, then tap `app-release.apk`.
3. Follow Android's installation prompt. If asked, allow only the browser or Files app to install unknown apps, then turn that permission off after MCode is installed.

Desktop builds for macOS, Windows, and Linux are covered in [Install](install.md).

## Troubleshooting

### The download never starts or never finishes

1. If the link opened inside Discord, GitHub, or another app, choose **Open in browser** / **Open in Chrome**, or copy it into a full browser.
2. Start the Android download again and wait for it to finish.

### Samsung Galaxy: Auto Blocker

If your Samsung Galaxy says **Auto Blocker** prevented the install, open **Settings → Security and privacy → Auto Blocker**, temporarily turn it off, install MCode, then turn it back on. Do not disable Play Protect.

### Pairing the phone to a runtime

- Desktop app host: see [Remote MCode Servers](remote-servers.md#mobile-from-a-headless-server) for `--mobile-pairing` QR codes.
- Keep the phone on the same tailnet, open MCode Mobile, choose **Pair**, and scan the QR code or paste the printed link.
